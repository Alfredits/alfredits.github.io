Palabra clave CODEX

Conecta Codex a Claude y ahorra límite

Instala el plugin oficial de Codex en Claude Code: Claude dirige y revisa, Codex escribe el código pesado con su propio límite.

GuíaClaude Code + ChatGPT10 minutosGratis

Cómo usarlo

  1. Abre Claude Code en tu carpeta.
  2. Pega los 4 comandos, uno por uno.
  3. Añade las reglas a tu CLAUDE.md para que Claude delegue solo.

Lo que necesitas

  • Claude Code (en la app de escritorio de Claude, pestaña Code; pide el plan Pro).
  • Una cuenta de ChatGPT. Codex está incluido en todos los planes, también en el gratis, con límites distintos.

1 · Añade el plugin

Escribe en Claude Code:

En Claude Code
/plugin marketplace add openai/codex-plugin-cc
En Claude Code
/plugin install codex@openai-codex
En Claude Code
/reload-plugins

Es el plugin oficial de OpenAI. Si te pregunta dónde instalarlo, elige el ámbito de usuario para tenerlo en todas tus carpetas. El tercer comando recarga los plugins para que aparezcan los comandos /codex; si aun así no salen, cierra y vuelve a abrir la app de Claude.

2 · Prepara Codex

En Claude Code
/codex:setup

Revisa si tienes Codex instalado; si no, te ofrece instalarlo (necesita Node.js: si no lo tienes, pídele a Claude «instala Node.js» y acepta). Cuando te lo pida, inicia sesión con tu cuenta de ChatGPT.

3 · Pásale trabajo

En Claude Code
/codex:rescue Arma el proyecto del reel siguiendo el brief de BRIEF.md

Con /codex:rescue Claude le pasa la tarea a Codex y te trae el resultado. También tienes /codex:review para que Codex revise lo que hizo Claude.

4 · Que Claude delegue solo

Pega esto en tu CLAUDE.md (¿no lo tienes? aquí está la plantilla):

Añade a tu CLAUDE.md
## Trabajo con Codex
- Cuando una tarea sea escribir mucho código (armar el proyecto de un video, animaciones, scripts largos o arreglos grandes), pásasela a Codex con /codex:rescue y un brief claro: qué hay que hacer, en qué archivos y cómo se ve terminado.
- Tú (Claude) decides, escribes el brief y revisas lo que devuelve Codex antes de enseñármelo. Si algo está mal, se lo devuelves a Codex con las correcciones en una sola tanda.
- Las tareas cortas (una edición pequeña, una pregunta) las haces tú directamente.
Nota de Alfredo

Así trabajo: Claude decide, escribe el brief y revisa; Codex construye. Es como tener dos editores, uno dirige y el otro ejecuta. Cada uno gasta el límite de su propia cuenta.
