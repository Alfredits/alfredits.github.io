Palabra clave RITMO

Quita los silencios de tu voz

Un script que deja cada pausa en una décima de segundo y acelera la voz un 10 % sin que suene rara.

ScriptPython + FFmpegSegundosGratis

Cómo usarlo

  1. Copia el prompt y el script.
  2. Pégalos en Claude Code o Codex: él instala lo que falte y lo ejecuta.
  3. Arrastra el audio nuevo a CapCut.

1 · El prompt (Claude instala todo por ti)

Escríbele a Claude Code o Codex
Quiero quitar los silencios de mi voz en off y acelerarla un poco.

1. Revisa si tengo Python y FFmpeg instalados. Si falta alguno, instálalo pidiéndome permiso.
2. Crea en esta carpeta el archivo voz_ritmo.py con el código que te pego abajo, sin cambiarlo.
3. Ejecútalo con mi audio: python voz_ritmo.py Brutos/[MI-AUDIO].mp3 Exportados/[MI-AUDIO]-rapida.wav
4. Dime cuánto duraba antes y cuánto dura ahora.

2 · El script

voz_ritmo.py
"""Quita silencios >0,22 s (deja 0,1 s) y acelera a 1,1x. Uso: python voz_ritmo.py assets/voz.mp3 assets/voz-rapida.wav"""
import subprocess,re,sys
src,dst=sys.argv[1],sys.argv[2]
log=subprocess.run(['ffmpeg','-hide_banner','-i',src,'-af','silencedetect=noise=-38dB:d=0.22','-f','null','-'],capture_output=True,text=True).stderr
st=[float(x) for x in re.findall(r'silence_start: ([\d.]+)',log)]; en=[float(x) for x in re.findall(r'silence_end: ([\d.]+)',log)]
dur=float(subprocess.check_output(['ffprobe','-v','error','-show_entries','format=duration','-of','csv=p=0',src]))
K=.05;keep=[];a=0
for s,e in zip(st,en):
    if e>=dur-.05: break
    keep.append((a,s+K)); a=e-K
keep.append((a,dur))
sel='+'.join(f'between(t,{x:.3f},{y:.3f})' for x,y in keep)
subprocess.run(['ffmpeg','-y','-hide_banner','-loglevel','error','-i',src,'-af',f"aselect='{sel}',asetpts=N/SR/TB,atempo=1.1",dst],check=True)

Qué hace exactamente

  • Busca las pausas de más de 0,22 s y las deja en 0,1 s.
  • Acelera la voz a 1,1× sin cambiar el tono.
  • Te devuelve un .wav limpio para editar.
Nota de Alfredo

Funciona solo con audio: úsalo con tu voz en off. Si lo usas con un video donde hablas a cámara, el audio se recorta pero la imagen no, y se desincronizan.
