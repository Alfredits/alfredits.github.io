Palabra clave SKILLS

Las 3 skills que instalo para editar

video-use corta, HyperFrames anima y earshot escucha. Las tres son gratis y de código abierto; Claude las instala por ti.

GuíaClaude Code20 minutosGratis

Cómo usarlo

  1. Abre Claude Code en tu carpeta de videos.
  2. Pega el prompt de cada skill, una por una.
  3. Prueba cada una con un video tuyo antes de pasar a la siguiente.

Qué es una skill

Un manual que le enseña a Claude a hacer algo concreto. Se instala una vez y Claude la usa sola cuando la necesita. Necesitas Claude Code (plan Pro de Claude); si no lo tienes, empieza por la guía de tu primer video.

1 · video-use: corta tus brutos

Le pasas tus brutos y corta los silencios y los errores leyendo la transcripción. Es de browser-use, código abierto.

Escríbele a Claude Code
Instálame la skill video-use (https://github.com/browser-use/video-use) para Claude Code.

1. Lee su install.md y sigue los pasos: clona el repositorio, instala sus dependencias y FFmpeg si no lo tengo, y regístrala en mi carpeta global de skills (~/.claude/skills/video-use).
2. Para transcribir, video-use usa ElevenLabs y necesita una clave de API. NO la configures todavía: pregúntame si quiero usar ElevenLabs o el transcriptor gratis de Whisper en mi computadora (https://alfredits.github.io/comunidad/texto/).
3. Si elijo Whisper, instálalo con ese script y, cuando use video-use, transcribe con él en lugar de ElevenLabs, guardando el resultado en el mismo formato que espera video-use.
4. Cuando termines, dime que está lista y no transcribas nada hasta que yo te pase un video.
Nota de Alfredo

Por defecto video-use transcribe con ElevenLabs, que pide una clave de API. Yo no la uso: transcribo gratis en mi computadora con el script de TEXTO, y el prompt ya le dice a Claude que te pregunte cuál quieres.

2 · HyperFrames: animaciones y textos

Claude escribe las animaciones y los textos de tu video con código y los convierte en MP4. Es de HeyGen, gratis y de código abierto.

Escríbele a Claude Code
Instálame la skill de HyperFrames (de HeyGen) para Claude Code, en mi carpeta global de skills.

1. Comprueba que tengo Node.js; si no, instálalo.
2. Ejecuta: npx skills add heygen-com/hyperframes
3. Cuando termine, haz una prueba corta: un video vertical de 5 segundos con el texto "Hola" animado, y dime dónde quedó el MP4.

3 · earshot: escucha tu audio

Claude no oye. Con earshot, escucha tu audio y te dice qué suena, cuándo y qué tan fuerte, para mezclar música y efectos. Funciona en el procesador, sin tarjeta de video.

Escríbele a Claude Code
Instálame earshot (https://github.com/Leonxlnx/earshot) y su skill para Claude Code.

1. Comprueba que tengo Python 3.10 o superior, uv y FFmpeg; instala lo que falte.
2. Instala earshot siguiendo su README y descarga sus modelos (pesan alrededor de 1 GB).
3. Copia sus skills de la carpeta skills/ a mi carpeta global de skills (~/.claude/skills).
4. Pruébalo con un audio o video mío: dime qué suena, cuándo y qué tan fuerte.
Nota de Alfredo

Las tres juntas son la base de cómo edito hoy: video-use corta, HyperFrames anima y earshot me dice si la mezcla está bien antes de exportar.
